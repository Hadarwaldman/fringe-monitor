Settings

Who's using the app, trip dates for the scanner, and account connections.

Active user

Schedules, bookings and date windows are stored per person on this device — switching here changes whose data every page shows.

Date window

Your trip dates, used to filter every page. The daily scan covers both people's windows combined.

Scanner

The full programme scan runs daily at 06:00 UTC; the watchlist and monitors re-check every 15 minutes. You can force a full scan now if you need fresh data.

Run a full scan?

This kicks off a full programme scan on AWS (~a few minutes, thousands of shows). It costs real money (Lambda + API usage). Don’t run it unless you need fresh data before the next daily scan.

PlanMyFringe account

Used by the Sync calendar button to pull your schedule, wishlist and scores from planmyfringe.co.uk. Credentials are verified with a real login, then stored encrypted on AWS (SSM SecureString) — they are never shown back here.
